# ParaDev Agent Guide

Read [docs/README.md](docs/README.md) first. It is the docs menu and authority map.

## Environment

Source of truth: **`requirements.txt` and `requirements-dev.txt`**. `pyproject.toml` reads them through setuptools dynamic metadata.

Install priority: **uv -> pip (requirements) -> pyproject -> conda -> poetry**.

- Edit `requirements.txt` (runtime) and `requirements-dev.txt` (dev extra), then run `rtk bash scripts/sync-env.bash`.
- `uv.lock`, `environment-dev.yml`, and `poetry.lock` are generated by `scripts/sync-env.bash`; `scripts/sync-env.bash --check` is the CI drift gate.
- Treat the published `heavenbase==0.1.2.2` package as the required runtime API.
- Use `scripts/sync-env.bash --heavenbase-source` only as a temporary editable
  source override for HeavenBase development. Repository wrappers preserve a
  verified override; a later plain `scripts/sync-env.bash` restores the
  published package.
- Keep the package version in `src/paradev/version.py`.
- Keep `README.en.md` canonical; `README.zh.md` is its line-aligned Simplified
  Chinese edition, and `README.md` is generated from the English source.
- New Bash wrappers must source `scripts/_env.bash` and use `resolve_uv`, `uv_run`, `run_python`, or `run_uv_python`.
- Git hooks live in `.githooks`; pre-commit runs env sync, stages generated README/env files, then runs `scripts/flake.bash --all`.

## Workflow

- New features: start from a Linear issue or create one from [docs/goals/short-term-plan.md](docs/goals/short-term-plan.md), read the linked docs, implement the smallest testable slice, update docs and Linear.
- Every active five-hour loop: apply heaven-style to changed code, run its vendored self-scan on `.agents/skills/heaven-style/scripts`, run targeted tests, review the diff, write a note in [docs/progress/](docs/progress/), then commit and push only intentional changes.
- `rtk bash scripts/test.bash` is the standard parallel fast gate and excludes `slow` tests. Use `rtk bash scripts/test.bash --full` for release or PIHC3 migration sign-off, `rtk bash scripts/test.bash --slow` for only slow PIHC3 parity contracts, and `--serial` when debugging order-sensitive failures.
- Default installed-GUI debugging uses `rtk uv run paradev dashboard`, which serves the packaged React app through the loopback API and prefers the macOS system WebView. Use `--app` for an explicit Chromium app window, `--browser` for a browser tab, and `--no-open` for host-only tests. `paradev-gui` is the compatibility entry point. Use `rtk bash scripts/run.bash --native-web` when a build-time browser preview must exercise local files, databases, build actions, open-path actions, or HoI4 launch actions through the loopback native bridge; plain `--web` is for browser-only layout checks.
- Detailed workflow commands: [docs/workflows/README.md](docs/workflows/README.md).
- Use [docs/goals/final-architecture.md](docs/goals/final-architecture.md) as the compiler architecture contract.
- Use [docs/architecture/interfaces.md](docs/architecture/interfaces.md) for CLI, SDK, MCP, REST, LSP, VS Code, and desktop boundaries.
