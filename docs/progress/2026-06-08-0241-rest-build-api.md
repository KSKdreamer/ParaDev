## Review

- The REST route does not introduce build logic; it delegates to the SDK-owned `Project.build(...)`.
- `POST /projects/build` dry-runs by default, matching CLI `build`.
- `emit_artifacts=true` performs a dry-run preflight first and returns the blocked plan instead of writing files when blocking diagnostics exist.
- `emit_manifests=true` follows existing SDK behavior and may write manifests for the returned build result.
- Default tests cover the OpenAPI seed and static contracts; runtime FastAPI route tests remain outside the default suite because `fastapi` is not installed in the default environment.
