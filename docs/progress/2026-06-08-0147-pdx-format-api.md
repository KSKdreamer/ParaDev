## Review

- The formatter is preview-first and mutates only with `write=True`.
- Parse failures, missing files, unreadable files, and failed writes return diagnostic payloads instead of raw exceptions.
- `format_pdx_text(...)` gives editor/GUI callers a no-filesystem path for unsaved buffers.
- `format_pdx_file(...)` writes only after parsing succeeds and the formatted text differs from the original.
- CLI, REST, MCP, and frontend contract metadata route to the SDK-owned formatter instead of duplicating behavior.
- PDX semantic edits, LSP text edit integration, and GUI form workflows remain out of scope for this slice.
