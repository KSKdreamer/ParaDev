# Diagram Hover I18n Slice

## Scope

Localized the focus-tree diagram node metadata shown in SVG titles and hover cards. The default helper output remains stable for callers that do not pass a translator, while the GUI now passes the active translator so Chinese users no longer see English labels such as `Grid`, `Mode`, `Size`, and `Priority` in node metadata.

## Changes

- Added translated diagram hover metadata keys in the English and Chinese locale bundles.
- Threaded the diagram translator into node hover cards and SVG `<title>` content.
- Kept existing English helper output unchanged when no translator is supplied.
- Added a regression test for localized tooltip text and hover-card rows.
