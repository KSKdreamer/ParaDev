# Open Target Icons

These files are packaged with the Vite frontend and system-WebView desktop application so the local-path opener dropdown does not depend on runtime network access.

- `finder.png`, `terminal.png`: converted from macOS system app icons on the development machine.
- `vscode.png`, `cursor.png`, `sublime-text.png`, `iterm2.png`: converted from installed desktop app icon resources on the development machine.
- `cmd.svg`, `powershell.svg`: downloaded from Microsoft VS Code Codicons.
- `explorer.svg`: downloaded from Microsoft Fluent UI System Icons.
